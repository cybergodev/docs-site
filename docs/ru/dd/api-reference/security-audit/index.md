# Безопасность и аудит

Система безопасности DD состоит из трёх независимых, но взаимодополняющих компонентов, охватывающих полную цепочку от маскирования данных до аудит-отслеживания.

## Обзор компонентов

| Компонент | Зона ответственности | Типовой сценарий |
|-----------|---------------------|-----------------|
| [SensitiveDataFilter](./security) | Автоматическое обнаружение и маскирование конфиденциальных данных в логах | Предотвращение утечки паролей, API-ключей, номеров кредитных карт |
| [AuditLogger](./audit) | Асинхронная запись событий, связанных с безопасностью | Аудит соответствия, анализ безопасности, обнаружение вторжений |
| [IntegritySigner](./integrity) | HMAC-подписи для предотвращения подделки логов | Защита от подделки, криминалистический анализ, хранение для соответствия |

## Взаимосвязь компонентов

```text
Поток записи логов:

  Logger.InfoWith(...)
       │
       ├─→ SensitiveDataFilter ──→ Маскирование значений полей (пароль → [REDACTED])
       │         │
       │         └─→ AuditLogger ──→ Асинхронная запись событий маскирования (какой лог и что было отфильтровано)
       │
       └─→ Форматированный вывод

  AuditLogger (опционально IntegritySigner) ──→ HMAC-подпись аудитных событий (защита от подделки)
```

- **SensitiveDataFilter** перехватывает конфиденциальные данные **до** записи логов
- **AuditLogger** записывает события безопасности асинхронно, не влияя на производительность основного логирования
- **IntegritySigner** **не встроен в обычный путь записи логов**: он подписывает только **аудитные события** (подключается через `AuditConfig.IntegritySigner`) или произвольные данные при ручном вызове `Sign`/`SignFields`

## Быстрый выбор

| Потребность | Рекомендуемый компонент |
|-------------|------------------------|
| Предотвращение утечки паролей/ключей | [SensitiveDataFilter](./security) |
| Запись «кто, что и когда сделал» | [AuditLogger](./audit) |
| Гарантия неподделанности логов | [IntegritySigner](./integrity) |
| Соответствие HIPAA/PCI-DSS | Все три вместе — см. [Настройка соответствия](../../guides/security/compliance) |
